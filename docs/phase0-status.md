# 阶段 0 验证状态

记录日期：2026-10-28。目标是先完成 Windows → Mac 的可测量鼠标移动链路，所有“未测”项目不得推定通过。

## 已实现

共享 Rust 核心；Windows Raw Input；Mac CoreGraphics 适配；离线身份配对与 Noise KK 加密会话；显式开启、暂停和停止；重连后暂停；有界累计位移合并；过期事件拒绝；异步有界日志与分段统计。

新增实机证据见 [Mac 验证记录](mac-validation-20261028.md)：Mac 原生 release 构建与 42 项测试通过，Wi-Fi 路径下十秒合成 DrySink 成功。随后完成首轮真实鼠标共享，用户反馈“能移动，比较流畅”。有线首轮存在握手超时差异，根因未定。主观观察不等于本地鼠标、ShareMouse 的受控对照通过。

后续 [有线复测与连接诊断](connection-validation-20261028.md) 已完成：原网络实现连续两轮十秒有线 DrySink 成功，首次异常未复现。两端核心同步到 `f93e5b8`，新增分阶段连接日志与可重复启动脚本；Windows 42 项普通测试及 5 项网络测试、Mac 40 项普通测试及 5 项网络测试通过。新版一分钟有线发送正常结束，Mac 合并处理 46,830 帧，日志完整，到期正常退出且无残留监听。发送计数为 46,831，相差 1 帧尚未定位；本轮未注入系统光标，不能替代流畅度实测。

首次实机片段只含移动。后续已加入显式实验键盘、按钮、拖动和滚轮，但尚未进行这些动作的系统注入验收；断线、接收端崩溃和权限撤销下的真实释放仍需补测。

用户离家期间继续开发键盘、屏幕排列和统一前端。新增共享有序输入队列（10 项测试）以及布局校验／穿越计算（6 项测试），Windows 当前合计 60 项普通测试通过，传输诊断的 6 项显式网络测试通过。键盘、按钮和滚轮队列尚未接入协议或系统注入；布局 CLI 可计算入口，但尚未切换真实控制权。`ui/index.html` 为离线布局草稿编辑器，不能开启共享。浏览器工具拒绝本地文件预览，未进行渲染及交互视觉验收；现场输入、ShareMouse 对照及长时间真实工作负载测试等待用户回家。新增模块已通过 Apple 目标类型检查，尚未在 Mac 原生重建。

前端 JavaScript 语法检查与 24 项内存 DOM/model 断言通过（本地检查脚本 `runs/ui-check.cjs`），覆盖非法导入保留旧数据、空草稿禁用导出、恢复本地草稿、Unicode 标识及小数边缘吸附；初始示例布局另经 Rust `layout-check` 验证通过。这些检查不含真实浏览器排版、指针拖动、文件下载或视觉检查。

## 现有证据

- 终端中断修复：CLI 已安装协作式停止处理器，Ctrl+C 不再直接绕过接收器释放和日志终结；普通发送线程的 join 错误也会先结束日志。Windows 80 项普通测试、原有 13 项显式 localhost 测试通过；新增两个隔离进程父测试通过（测试入口另含一个子进程辅助项，不计为独立验收）。在隐藏的独立控制台中实际生成 Ctrl+C / Ctrl+Break，模拟接收器已持有的键和按钮各释放一次；真实 CLI DrySink 接收器收到 Ctrl+Break 后正常退出、日志完整、监听关闭。没有捕获或注入系统输入。两端原生 release 均基于 `cc7e630d6f630f4b969b0e5673cf8f43f9465a0a`，`build_dirty=false`；fmt、Clippy 和 Apple 全目标类型检查通过。Mac 的 76 项普通测试、13 项网络测试及两个进程父测试通过；fake 接收器覆盖 SIGINT / SIGTERM / SIGHUP，CLI DrySink 覆盖 SIGINT（未测试 CLI 的 TERM/HUP）。Mac 证据目录为 `runs/mac-cc7e630-validation`，测试后没有残留项目进程。强制终止、崩溃、Windows 控制台关闭仍未验收。

- 协议 v2 与有序发送已接入两端适配层，Windows 80 项普通测试及 13 项显式加密网络测试通过；其中 7 项覆盖完整输入顺序、持有按键时暂停／断线／紧急停止、适配器失败与释放失败，以及重连后手动启用。全部使用记录适配器，不操作系统键鼠。Mac 原生 76 项普通测试及 13 项网络测试通过。两端 release 均为 `f4d6a810e793cb9e186c608606eb4a756c35b30e`、`build_dirty=false`，Mac 已验证实际 arm64 系统框架链接。新增物理捕获／输入注入仍未运行。

- 发现并修正初次连接后立即启用的控制帧竞争，以及采集时间早于发送线程轮询时间导致的错误暂停；新增回归测试保留实际捕获时间，不把锁等待从延迟数据中删除。
