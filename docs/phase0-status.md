# 阶段 0 验证状态

记录日期：2026-10-28。目标是先完成 Windows → Mac 的可测量鼠标移动链路，所有“未测”项目不得推定通过。

## 已实现

共享 Rust 核心；Windows Raw Input；Mac CoreGraphics 适配；离线身份配对与 Noise KK 加密会话；显式开启、暂停和停止；重连后暂停；有界累计位移合并；过期事件拒绝；异步有界日志与分段统计。

新增实机证据见 [Mac 验证记录](mac-validation-20261028.md)：Mac 原生 release 构建与 42 项测试通过，Wi-Fi 路径下十秒合成 DrySink 成功。随后完成首轮真实鼠标共享，用户反馈“能移动，比较流畅”。有线首轮存在握手超时差异，根因未定。主观观察不等于本地鼠标、ShareMouse 的受控对照通过。

后续 [有线复测与连接诊断](connection-validation-20261028.md) 已完成：原网络实现连续两轮十秒有线 DrySink 成功，首次异常未复现。两端核心同步到 `f93e5b8`，新增分阶段连接日志与可重复启动脚本；Windows 42 项普通测试及 5 项网络测试、Mac 40 项普通测试及 5 项网络测试通过。新版一分钟有线发送正常结束，Mac 合并处理 46,830 帧，日志完整，到期正常退出且无残留监听。发送计数为 46,831，相差 1 帧尚未定位；本轮未注入系统光标，不能替代流畅度实测。

阶段 0 第一片段只含移动，不注入按钮或键盘，因此暂不存在由本程序按住的远端按钮状态。后续添加按钮前，必须完成断线、接收端崩溃和权限撤销下的释放测试。

## 现有证据

- Windows Rust release 可构建。
- 初始基线通过 37 项单元测试及 5 项单独执行的网络测试。控制窗口改动后，新增两项状态/启停测试，39 项普通测试通过；未改变协议和网络实现。Mac 基线原生 42 项测试也通过。
- `cargo clippy --all-targets -- -D warnings` 无警告。
- `cargo check --target aarch64-apple-darwin` 通过；此外已在 Mac 实际完成原生链接与运行，两种证据分开记录。
- Windows 初始短时测试没有物理事件；本次 90 秒采样测试记录 6,518 个运动包。首轮跨机实际输入记录 11,633 个运动包，用户开启、暂停、再次开启，发送端提前正常退出，运行约 46.74 秒。
- Windows 提供原生控制窗口与开始/暂停/停止按钮；Ctrl+Alt+Space 开始或暂停，Ctrl+Alt+Esc 停止。界面与共享核心状态一致，未连接禁用开始，断线后等待重新启用。
- 本机加密回环 `loopback-20261028-003922-593` 已完成。3 秒合成输入发送 2,317 帧，接收端处理 2,271 次合并后的移动；源端处理 P95 1.0446 ms，接收端软件处理 P95 0.0084 ms。两端日志完整、记录丢失为零。发送进程正常结束后，接收日志记录了一次预期的连接关闭。这里的接收器是 DrySink，没有系统注入，不能替代 Windows → Mac 实机测试。
- 新增 `session_recovery` 的两项真实认证连接测试通过：断线前未发送的累计位移不会在重连或重新 ARM 时注入；连接持续收到新许可心跳时，使用旧许可的移动仍被拒绝。只调用共享核心与 DrySink，不操作系统输入。
- 日志现在同时报告完整输入间隔及筛选后的运动段间隔，超过 50 ms 的间隔保留在完整分布中，不能自动判为无害空闲。写入或刷新失败会向调用方报错；摘要检查时间倒退、缺少字段及损坏结尾。
- 新构建的环境输出和日志 metadata 包含 Git 提交、工作区修改标记、编译器和构建时间。未提交构建明确标为 dirty，缺少 Git 的归档构建明确标为 unknown。

Mac 执行通道已建立，源码和 Git 历史已导入。实机为 M4 MacBook Air、macOS 27.0.1，主屏逻辑分辨率 1470×956，系统声明 60 Hz；实际刷新率未测。当前辅助功能、事件发送、输入监控预检允许，实际光标控制已有用户观察；Mac Escape 停止仍待验证。
